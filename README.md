# RainonUI



Features



UI Declutter

Hide selected default interface elements you don't want cluttering your screen, with settings that persist between sessions.



Raid \& Utility Reminders

Clean on-screen alerts for the moments that matter during group content: break timers, ready checks, feasts and food, cauldrons and flasks, repairs, mail, healthstones, mage table, summons and more. Reminders are timing-aware, so they only appear when they're actually relevant.



Movable Blizzard Frames

Reposition and rescale key default frames — combat timer, bonus roll, Mythic+ keystone, currency and profession trackers — and lock them exactly where you want.



Handy Tabs

Quick-access panels for Professions, Currency and useful Links, all in one draggable window.



Fully Customizable

Every movable element supports drag-to-position and mouse-wheel scaling (0.5×–2.0×), with all positions saved automatically. Elements can be arranged via the built-in editor.



Usage



Open the main window with /rainonui (or the short form /rs).
