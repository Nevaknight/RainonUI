RainonUI — звуки (Media\Sounds)

Скопируй сюда свои ogg-файлы со СТРОГО такими именами:

  allready.ogg     — «Все готовы»
                     (бывший: 0 All ready - Alice by Rainon.ogg)
  break.ogg        — «Перерыв» (свой звук; раньше играл allready)
  feast.ogg        — сытная еда (0 Food Hearty Well Fed - ...)
  food.ogg         — обычная еда (0 Food - ...)
  racechange.ogg   — смена расы (0 Change Race - ...)
  repair.ogg       — ремонт (0 Repair - ...)
  cauldron.ogg     — котёл (0 Boiler - ...)
  mail.ogg         — почта (0 Mail Box - ...)
  healthstones.ogg — камни здоровья (0 Health Stones - ...)
  magetable.ogg    — стол мага (0 Mage table - ...)
  summon.ogg       — шкаф сумона (0 Ritual of Summoning - ...)
  leader.ogg       — лидер группы (0 Lead group - ...)

Формат: OGG (или MP3). Если файла нет — аддон молчит, без ошибок.
После добавления файлов нужен перезапуск игры (звуки кэшируются
при старте клиента).
