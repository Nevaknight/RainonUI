# RainonUI — Changelog

## 1.7.0

* **Crafting Order Queue can now be turned on in Professions settings.** A new "Order Queue (test)" checkbox sits right above the automatic window switching option. It is off by default; while it is off, the queue window does not open by itself.
* **Fixed the queue getting stuck on "Crafting…".** Using Shatter Essence (or any craft that does not create an item) right before taking an order no longer freezes the queue button.
* **Redesigned queue window.** All buttons are now the same size in two neat rows at the top, orders fill the dark panel below them, and the price settings sit together above the "Next" button. The title reads "RainonUI — Order Queue", the order list uses a larger font, and Esc closes the window.
* **Keybind and macro for "Next".** Bind a key in Game Menu → Options → Keybindings → AddOns → RainonUI, or use the macro /rsorders next.
* **Right-click an order in the queue** to mark why you skip it or to blacklist the ordered item — right in our window.
* **Recipes you don't know yet** are shown in red with an estimated profit, so you can see at a glance whether a recipe is worth learning.
* **The separate bag-opening buttons in the queue window were removed** — the bag macros keep working on their own.
* **Knowledge & Charges:** the "i" help button now sits on top of the window frame, and the Enchanting Shimmering Dust catch-up amount is calculated correctly.
